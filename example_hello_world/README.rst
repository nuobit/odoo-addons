Usage
=====

This module creates a simple "Hello World" application that demonstrates:

1. **Model Structure**: Shows how to create models with different field types
2. **Views**: Demonstrates tree, form, and search views with proper widgets
3. **Actions**: Shows button actions and their implementation
4. **Data**: Includes sample data records
5. **Menu Structure**: Shows how to create menu hierarchies

The module creates a "Hello World" menu in the main Odoo interface where you can:

- Create greetings with different priorities
- View and edit greeting messages
- Increment greeting counters
- Filter and search records
