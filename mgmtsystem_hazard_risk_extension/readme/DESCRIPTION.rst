This module makes the hazard risk computation formula descriptions
translatable and ships their Spanish and Catalan translations.

The base module presents the risk formulas (for example
*Risk = Probability (A) x Severity (B) x Usage (C)*) only in English. This
extension turns the formula description field into a translatable field and
provides the Spanish and Catalan wording, so the formulas are shown in the
user's language.
