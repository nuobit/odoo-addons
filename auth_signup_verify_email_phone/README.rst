Installation
============

- Install `phonenumbers <https://pypi.org/project/phonenumbers/>`_
  with ``pip install phonenumbers`` and restart the server to enable phone validation functionality.

  .. important::

     This library is required to enable proper phone number validation.
     Without it, the system will not be able to correctly process or validate phone inputs.

Configuration
=============

To configure this module, you **must**:

- Update the ISO code in *Settings > Translations > Languages* to match the ISO-639-1 standard.

  .. warning::

     This step is important: If the ISO codes are not correctly updated, the system **will not be able to match** the languages with the Facebook templates.
