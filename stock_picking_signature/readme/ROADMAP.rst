* Integration with ``sign_oca`` (`OCA/sign <https://github.com/OCA/sign>`_) for PDF
  document signing workflows on stock pickings.
* Integration with ``stock_picking_portal``
  (`OCA/stock-logistics-workflow <https://github.com/OCA/stock-logistics-workflow>`_)
  for portal-based signature capture, allowing external partners to sign pickings
  directly from the portal.
