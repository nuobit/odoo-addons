To give a company its own master folder for a menu:

#. Go to *Knowledge > Pages > Categories* (or *Management System >
   Configuration > Categories*).
#. Create or open the category that will hold the documents of that company.
#. Set its *Company* and its *Master Folder Of* (for example *Procedures*).

From then on, *Create* in that menu files the new pages of that company in
this category.
