Glue module between ``web_app_icon_flat`` and ``website``: it makes Odoo 16
show the flat Website icon, instead of the Odoo 16 one, on the Editor button
that the website shows to its editors.

Known issues / Roadmap
======================

* The «Course» item of the website's «New content» dialog keeps its Odoo 16
  picture: Odoo never drew a flat one, and the file is the same from version
  16 to version 20.
