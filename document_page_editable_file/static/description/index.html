Document Page Editable File

Adds an Editables tab to the documents of the Knowledge application, right after History, to keep the editable files of the document, such as the Word file its PDF comes from.

  • The tab has one field, which works like the content of the document: the files are inserted with the editor, the same way as the PDF in the content, and they are saved with the document.
  • Only the users who can edit the documents, the Knowledge editors and managers, see the tab and its field.
  • Each version of the document keeps the editable files that the document had while that version was the current one, in an Editables tab of its own form.
  • A file saved in the tab belongs to the tab: it does not show among the attachments of the document, and only whoever sees the tab can download it, even with its link.

Installation

The module depends on document_page_access_group and document_page_extension, which are installed with it.

  • document_page_access_group adds the Security tab to the documents, where a manager picks the groups that can see each document. A document with no groups is visible to every Knowledge reader, as before.
  • document_page_extension gives a file of a document only to whoever can read the document, even with the link of the file.

Usage

The Editables tab is for the users who can edit the documents: the Knowledge editors and managers. A user who only reads the documents does not see it.

To store the editable files of a document, edit the document, go to the Editables tab, insert the files the same way as in the content and save the document.

To see the editable files of an earlier version, open the version from the History tab of the document: its form has an Editables tab too.

Known issues / Roadmap

  • A file inserted in the Editables tab belongs to the tab once the user who inserted it, or a system administrator, saves it there. A file inserted and then discarded stays an ordinary attachment of the document, or of the version, and every user who reads the document can download it.
  • A user who only reads the documents can still filter the documents by the text of their Editables through the API: Odoo 14 does not apply the groups of a field to a search filter. The user learns which documents match, but gets neither the field nor its files.
  • The information inside the Word file, such as the author, the tracked changes or the comments, is not cleaned.
