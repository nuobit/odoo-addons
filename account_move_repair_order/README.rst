==========================
Account Move Repair Order
==========================

This module adds a repair order number field to the invoice form, allowing
users to link invoices with their related repair orders.

Features
========

* Adds a repair order field to invoices
* Displays repair order number on the invoice form
* Establishes relationship between repair orders and invoices
