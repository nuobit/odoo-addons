Makes the editable files of ``document_page_editable_file`` follow the change
requests of ``document_page_approval``:

* The files of a change request reach whoever the change request reaches: its
  author while it is a draft, and the approvers too once it is sent for
  approval. Every editor sees those of the version the document shows.
* Where a document requires approval, the files of a version change only while
  it is a draft change request, as its content does. Where it does not, they
  change while it is a draft change request too, and while the document shows
  it, as without approval.

Usage
=====

Where a document requires approval, its editable files change only in a draft
change request:

#. Change the content of the document and save it: this makes a change request,
   sent for approval.
#. Open the change request with the document's *Change Requests* button, press
   *Cancel* and then *Back to draft*: *Back to draft* alone refuses a change
   request that was sent for approval.
#. Change its editable files on its *Editables* tab, save, and send it for
   approval.

A change request created from *Change Requests* starts as a draft: save it
first, since its *Editables* tab stays read-only until it is saved. Once
approved, a change request is the version the document shows, with its files;
it is a new version even when only its editable files changed.

Where a document does not require approval, the usage of
``document_page_editable_file`` holds.

Known issues / Roadmap
======================

* Uninstalling ``document_page_approval`` deletes its change requests that are
  not approved, and this module deletes their editable files first. Uninstalled
  alone before it, this module does not: the attachments that hold the contents
  of those files then stay once ``document_page_approval`` goes, until
  ``document_page_editable_file`` is uninstalled.
