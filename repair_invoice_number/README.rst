===================
Repair Invoice Number
===================

This module adds repair order number to invoices, providing traceability between repair orders and their related invoices.

Features
========

* Adds a repair order reference field to invoices
* Automatically links repair orders to their invoices when created
* Shows repair order number in invoice forms and lists
* Provides easy navigation from invoice back to repair order

Usage
=====

When creating an invoice from a repair order, the repair order number will automatically be linked to the invoice. You can also manually set the repair order reference when creating an invoice.
